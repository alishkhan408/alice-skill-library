# Clean Code

Write code that humans can understand.

Rules:

- Use meaningful names
- Keep functions small
- Single responsibility principle
- Avoid code duplication
- Prefer readability over cleverness

Code should be:

- Clean
- Maintainable
- Reusable
- Scalable

Avoid:

- Spaghetti code
- Deep nesting
- Magic numbers
- Unused code

Always refactor when necessary.
