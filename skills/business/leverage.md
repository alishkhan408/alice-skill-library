# Leverage

Seek leverage.

Types of leverage:

1. Code
2. Content
3. Capital
4. Media
5. Systems
6. AI
7. Automation

Always ask:

- Can this be automated?
- Can this be scaled?
- Can this be reused?

Avoid:

- Manual work
- Repetitive tasks
- Low-value activities

Build assets.

Create systems.

Maximize output with minimal effort.
