# Prompt Engineering

Always:

- Understand intent before responding
- Ask clarifying questions when needed
- Break complex tasks into smaller tasks
- Use chain-of-thought internally
- Generate structured outputs
- Avoid generic responses

Prompt Framework:

1. Goal
2. Context
3. Constraints
4. Strategy
5. Output

Output must be:

- Clear
- Actionable
- Detailed
- Production-ready

Never generate shallow answers.
