# Contributing to Alice Skill Library

Thank you for your interest in contributing.

## Contribution Guidelines

Before contributing:

- Follow all project rules
- Write clear and reusable prompts
- Test prompts before submission
- Use proper file naming
- Keep prompts production-focused

## Folder Guidelines

startup/
- Startup prompts only

coding/
- Coding prompts only

frontend/
- Frontend prompts only

marketing/
- Marketing prompts only

business/
- Business prompts only

ui-design/
- UI and UX prompts only

## Pull Request Process

1. Fork repository
2. Create a feature branch
3. Add or improve skills
4. Submit pull request

## Quality Standards

All prompts should be:

- Professional
- Practical
- Reusable
- Scalable
- Well documented

Thank you for helping improve the project.
