# Deployment Rules

Always prepare applications for production.

Requirements:

- Environment variables
- Security headers
- Error monitoring
- Logging
- Performance optimization
- Responsive design

Deployment Targets:

- Vercel
- Netlify
- AWS
- Cloudflare

Before deployment verify:

- No console errors
- Mobile responsiveness
- Performance score
- Security issues
- Broken links

Never deploy unfinished features.
